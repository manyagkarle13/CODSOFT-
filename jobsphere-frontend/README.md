# JobSphere Frontend - CodSoft Job Board Task

This is the React + Vite frontend for JobSphere, my branded implementation of the **CodSoft Web Development Internship - Job Board** project task.

Live frontend: https://jobsphereweb.netlify.app/

Backend API: https://jobsphere-backend-exta.onrender.com

The girl shown in the web app hero section is AI-generated and used as a visual design asset.

## Features

- Landing page
- Candidate and employer authentication screens
- Candidate dashboard
- Employer dashboard
- Job search and listings
- Application tracking
- Responsive desktop and mobile layouts

## Local Setup

```bash
npm install
npm run dev
```

Local URL:

```text
http://localhost:5173
```

## Environment

Create a `.env` file:

```env
VITE_API_URL=http://localhost:5000
```

For Netlify deployment:

```env
VITE_API_URL=https://jobsphere-backend-exta.onrender.com
```
